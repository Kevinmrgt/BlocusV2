### Database Schema
[Source: docs/architecture/database-schema-postgresql-ddl.md]

**walls table:**
- `id`: UUID
- `gym_id`: UUID (FK to gyms)
- `name`: TEXT
- `description`: TEXT | null
- `order_index`: INTEGER (for display order)
- `created_at`, `updated_at`: TIMESTAMPTZ

**boulders table:**
- `id`: UUID
- `wall_id`: UUID (FK to walls)
- `title`: TEXT
- `description`: TEXT | null
- `difficulty`: INTEGER (1-10)
- `created_at`, `updated_at`: TIMESTAMPTZ

**boulder_photos table:**
- `id`: UUID
- `boulder_id`: UUID (FK to boulders)
- `url`: TEXT
- `order_index`: INTEGER

### API Query Patterns
[Source: docs/architecture/api-specification.md]

```typescript
// Get walls for a gym, ordered by order_index
const { data, error } = await supabase
  .from('walls')
  .select('*')
  .eq('gym_id', gymId)
  .order('order_index');

// Get boulders for a wall with photos
const { data, error } = await supabase
  .from('boulders')
  .select(`
    *,
    boulder_photos (id, url, order_index)
  `)
  .eq('wall_id', wallId)
  .order('created_at', { ascending: false });
```

### Query Keys Pattern
[Source: docs/architecture/api-specification.md]

```typescript
export const queryKeys = {
  walls: {
    byGym: (gymId: string) => ['walls', 'gym', gymId] as const,
  },
  boulders: {
    byWall: (wallId: string) => ['boulders', 'wall', wallId] as const,
  },
};
```
