### Database Schema
[Source: docs/architecture/database-schema-postgresql-ddl.md]

Tables to seed:
```sql
-- gyms
id UUID PRIMARY KEY,
name TEXT NOT NULL,
address TEXT NOT NULL,
latitude DOUBLE PRECISION NOT NULL,
longitude DOUBLE PRECISION NOT NULL,
description TEXT

-- walls
id UUID PRIMARY KEY,
gym_id UUID NOT NULL REFERENCES gyms(id),
name TEXT NOT NULL,
description TEXT,
order_index INTEGER DEFAULT 0

-- boulders
id UUID PRIMARY KEY,
wall_id UUID NOT NULL REFERENCES walls(id),
title TEXT NOT NULL,
description TEXT,
difficulty INTEGER NOT NULL CHECK (1 <= difficulty <= 10)

-- boulder_photos
id UUID PRIMARY KEY,
boulder_id UUID NOT NULL REFERENCES boulders(id),
url TEXT NOT NULL,
order_index INTEGER DEFAULT 0
```
